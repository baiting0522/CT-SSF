# CT-SSF code
Official implementation for Conformalized Time Series with Semantic Features (CT-SSF).

Our code leverages several related open-source resources from prior work, including [HopCPT](https://github.com/ml-jku/HopCPT) (Auer et al., 2023), [Feature CP](https://github.com/AlvinWen428/FeatureCP?tab=readme-ov-file)(Teng et al., 2022), [SPCI](https://github.com/hamrel-cxu/SPCI-code) (Xu et al., 2023), and [ACI-related methods](https://github.com/herbps10/AdaptiveConformal)(Susmann et al., 2024). We thank the authors of these projects. For comprehensive information on these baselines, please refer to the respective sources.

Run the following command to install dependencies:
```
pip install -r requirements.txt
```

If you find our work useful, please consider citing it.
